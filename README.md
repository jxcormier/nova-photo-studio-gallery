# Nova Photo Studio gallery

Original, brand-free reference pictures for Nova's Photo Studio. Every picture was made with an AI image
model for this gallery. Products, brands and text in them are invented, and no picture copies a real ad.

Served through jsDelivr, pinned by tag:

    https://cdn.jsdelivr.net/gh/jxcormier/nova-photo-studio-gallery@<tag>/inspiration/<id>.webp

`manifest.json` lists every picture with its category, title, size and suggested shot type.
